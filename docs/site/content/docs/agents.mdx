---
title: Agent-Skill
description: Installiere den Prex-Skill für Agenten und teile Preview-Links mit ihnen.
---

Installiere den Skill im aktuellen Projekt oder global für deinen Benutzer.

```sh
npx skills add https://prex.djl.foundation --skill prex
npx skills add https://prex.djl.foundation --skill prex --global
```

Für einen bestimmten Agenten kannst du beispielsweise `--agent codex` anhängen. Der Skill wird aktiv, wenn du nach einer Preview fragst. Er beschreibt die CLI-Nutzung, die Auswahl des Projekt-Scripts und den Umgang mit laufenden Sessions.

```sh
npm install -g @jackatdjl/prex
```

Agenten und Crawler können über [llms.txt](/llms.txt) in die Dokumentation einsteigen. [llms-full.txt](/llms-full.txt) enthält die Dokumentation als zusammenhängenden Markdown-Text.
