---
title: Erste Schritte
description: Starte einen bestehenden Dev-Befehl mit einem freien lokalen TCP-Port.
---

Prex benötigt Node.js ab Version 22 und ist für Linux und macOS vorgesehen. Installiere die CLI mit npm:

```sh
npm install -g @jkxrx/prex
```

```sh
prex bun run dev
prex run --ports 2 -- ./dev-stack
```

Der erste Port steht als `PORT`, `PREX_PORT` und `PREX_PORT_1` bereit. Weitere Ports erhalten fortlaufende Nummern. Next.js verwendet `PORT` als Vorgabe. Wenn dein Server ein Argument wie `--port` erwartet, definiere ein [Projekt-Script](/docs/configuration/).
